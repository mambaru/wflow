# Учебник wflow

**wflow** — библиотека поверх Boost.Asio. Она помогает ставить задания в очередь, выполнять их сразу или позже, ограничивать нагрузку, запускать таймеры и при необходимости крутить свой пул потоков. Глубоко знать Asio не обязательно: достаточно понимать, что `io_context` — это движок событийного цикла. Пока в нём есть работа (или есть «страж», который не даёт циклу завершиться), `run()` крутится и вызывает ваши обработчики.

Соберите проект с примерами (см. [главный Readme](../Readme.md)), читайте главы по порядку и сверяйте вывод с кодом в `examples/`.
